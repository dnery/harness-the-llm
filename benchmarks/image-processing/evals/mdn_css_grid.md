# Eval: `mdn_css_grid`

## Expected screenshot understanding

The output should identify an MDN Web Docs page about CSS Grid layout basic concepts. It should recognize a technical documentation page with side navigation, article hierarchy, code/examples, and reference/documentation chrome.

## High-value regions

- MDN global header with logo, search, theme/language controls, and top navigation when visible.
- Breadcrumbs or page path identifying CSS / Guides / Grid layout / Basic concepts.
- Left documentation navigation/sidebar with related CSS topics.
- Main article heading and introductory paragraphs.
- Right "In this article" table of contents when visible.
- Code blocks, syntax examples, diagrams, or rendered layout illustrations.
- Compatibility, feedback, or footer widgets if visible.

## Content expectations

- Capture the page title and several visible section headings in hierarchy.
- Distinguish article prose from sidebar navigation and right-side contents.
- Preserve code snippets or CSS property names when legible.
- Identify diagrams/examples as visual elements associated with grid tracks, columns, rows, or layout concepts when visible.
- Use structured lists for sidebars and article contents where possible.

## Common failure modes to penalize

- Collapsing the whole page into a generic "CSS tutorial" without layout structure.
- Ignoring sidebars, breadcrumbs, or article table of contents.
- Inventing code not visible in the screenshot.
- Misclassifying MDN as Mozilla homepage or a search page.
- Missing local uncertainty for small code text.
